## Problem

### Print Squares

Write a program that utilizes a while loop to print the squares of numbers from 1 to 5.

### Sample 1:
Input
Output

```

```


## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-06T01:17:59.677Z  

```java
public class Main {
    public static void main(String[] args) {
        int num = 1;
        while (num <= 5) {
            System.out.print((num * num) + " ");
            num++;
        }
    }
}
```
